## Filing rules
- One note = one topic. Create a note only when an existing one does not fit; add it to the table above.
- Short additions, absolute dates (YYYY-MM-DD), delete what becomes wrong rather than piling up.
- Big files (PDF, photos, exports) stay in your drive or tool: note only their name and location here.
- No secrets, no personal contact details, no judgements about people (the filter blocks the first two).
